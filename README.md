# SQL-samples

## Стек

MySQL, PostgreSQL

## Примеры решённых кейсов
- Аналитика вовлечённости пользователей — расчёт LT (lifetime), поиск дня с максимальной активностью среди дней с более чем 500 уникальными пользователями.
- Аналитика прослушиваний аудиокниг — определение книги, которую чаще всего дослушивают до конца; сегментация пользователей по проценту прослушивания.
- HR-аналитика (учебная БД employees) — сотрудники, работавшие в нескольких департаментах; ранжирование по стажу; зарплата выше среднего по отделу; следующая должность в карьере сотрудника (LEAD).
- Проектирование учебных баз данных с нуля (university, family) с внешними ключами и заполнением тестовыми данными.
